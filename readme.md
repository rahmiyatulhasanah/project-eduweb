# Project-Based Internship Assignment  

## About the Assignment  
This project involves creating a landing page for a fictional training institution called **Edura**. The institution specializes in providing training in digital skills such as **Software Engineering**, **Web Development**, **Game Development**, **AI Science**, and **Cybersecurity**.  

To achieve better code organization, I plan to write each section of the website in separate HTML files. Typically, websites include sections such as navigation, header, and footer. For this assignment, I will integrate the header within the navigation section, as illustrated in the provided `.png` file accompanying this project.  

## Website Structure  
The HTML structure for this website includes the following sections:  
1. **Institution Profile**  
2. **Training Programs**  
3. **Training Information**  
4. **News and Articles**  
5. **Photo and Video Gallery**  
6. **Contact Information**  
7. **Navbar and Header**  
8. **Footer**
